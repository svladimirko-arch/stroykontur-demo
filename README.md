# СтройКонтур — демо-версия сайта

Статический демо-сайт для предоставления заказчику по проекту с Kwork.
Собственная визуальная концепция: тёмно-синий + активный синий + точечный янтарь.
Дизайн, тексты и изображения не скопированы с референса `int-stroy96.ru` — использован
только общий смысл ТЗ.

## Палитра

Токены определены в `assets/css/style.css` в `:root`:

| Токен | Цвет | Где используется |
| --- | --- | --- |
| `--color-primary` | `#0B2A4A` | header, footer, брендовые акценты |
| `--color-primary-block` | `#1B4F7E` | контентные тёмные блоки — на 3 тона светлее базового синего |
| `--color-secondary` | `#1D4ED8` | ссылки, иконки, secondary-кнопки, focus-кольцо, активные состояния |
| `--color-accent` | `#F59E0B` | только главные CTA и важные акценты (промо-плашки, звёзды рейтинга) |
| `--color-bg` | `#FFFFFF` | основной фон страниц и карточек |
| `--color-bg-muted` | `#F3F4F6` | чередующиеся светлые секции |
| `--color-text` | `#0F172A` | основной текст |
| `--color-text-muted` | `#475569` | вторичный текст, подписи, meta |
| `--color-border` | `#E2E8F0` | границы, разделители, линии |

Соблюдается пропорция 60/30/10; градиенты, неон и «жёлто-чёрный стереотип стройки» не используются.

## Как открыть

Просто откройте `index.html` в браузере. Для корректной работы всех ссылок можно
запустить локальный сервер из папки `demo`:

```powershell
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000/`.

## Заглушки — обязательно заменить перед запуском

1. **Контакты** (во всех HTML-файлах помечены комментарием `ЗАГЛУШКА`):
   - телефон `+7 (XXX) XXX-XX-XX` и `tel:+70000000000` (также в JSON-LD);
   - e-mail `info@example.ru`;
   - адрес `г. Екатеринбург, ул. __________, __`;
   - ссылки мессенджеров `#`.
2. **Цены**: все позиции в прайсах указаны как `0,00 ₽` — заменить реальными значениями.
3. **Домен**: `stroykontur.example.ru` в `canonical`, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`.
4. **Статистика и метрики**: счётчики-заглучки «12 лет», «150+ объектов» и отзывы — демонстрационные.
5. **Формы**: отправка на бэкенд не происходит. В `assets/js/main.js` в обработчике
   `form[data-demo-form]` есть комментарий, где подключать AmoCRM/Telegram/API и цель
   Яндекс.Метрики `ym(XXXXXXXX, 'reachGoal', 'lead')`.
6. **Яндекс.Метрика**: закомментированный блок с `ym(XXXXXXXX, ...)` в конце страниц.
7. **Политика конфиденциальности**: ссылка в форме главной ведёт на `#contacts` — нужна отдельная страница.
8. **Офер на главном экране**: скидка 10% при заказе двух услуг указана для демо; замените
   текст акции на реальное условие перед запуском.

## SEO, уже реализованное

- Уникальные `title`, `description`, `og:*`, `canonical` на каждой странице.
- `H1–H3`, хлебные крошки и `BreadcrumbList` JSON-LD, `GeneralContractor` JSON-LD.
- ЧПУ-адреса (`remont-kvartir.html` и т. п.; при переходе на CMS — без `.html`).
- `sitemap.xml`, `robots.txt`, `alt` у всех информационных изображений.
- Адаптивная вёрстка от 320 px: мобильное меню, перенос длинных заголовков, подсказка прокрутки прайса, увеличенные области нажатия.
- Lazy-загрузка фото, пауза видео вне экрана, `prefers-reduced-motion`.
